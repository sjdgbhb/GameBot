# 常见问题与踩坑

> 开发和运行中常见的问题及解决方案。

## 环境相关

### 大漠 COM 创建失败
- **原因**：在 64 位 Python 中直接创建大漠 COM 对象
- **解决**：大漠 COM 只能在 32 位 Python 3.8 中创建，主环境通过 dm_bridge 子进程调用
- **检查**：确认 `.venv-dm` 存在且是 32 位 Python 3.8

### 大漠 DLL 未注册
- **原因**：dm.dll 未注册或版本不匹配
- **解决**：运行 `uv run python -m GameBot.dm_bridge --register`（需管理员权限）
- **检查**：确认 `external/dm/dm.dll` 存在

### Python 版本不匹配
- **原因**：主环境不是 Python 3.12
- **解决**：`main.py` 启动时校验 Python 3.12，不满足会报错退出
- **检查**：运行 `uv run python --version` 确认

## 窗口操作相关

### 后台输入后画面不刷新
- **原因**：KK 平台 Qt 窗口是 layered 窗口，后台输入后不重绘
- **解决**：调用 `force_refresh_layered(hwnd)` 刷新
- **约束**：不能在 `bind_window` 上下文内调用，需拆成两段 bind
- 详见 [KK平台特性](../domain/kk-platform.md)

### 后台操作落空（无报错但操作无效）
- **原因**：大漠绑定状态被破坏（如 layered 刷新后未重新绑定）
- **解决**：确保每次操作前窗口已正确绑定
- **检查**：在 bind_window 上下文内操作，不要在刷新 layered 后直接操作

### 多开时窗口认领错误
- **原因**：多个 KK 实例窗口外观相同，操作了错误的窗口
- **解决**：通过 OCR 玩家名匹配窗口归属
- **检查**：确认 multi_instance 配置正确

## 截图与 OCR 相关

### OCR 识别乱码
- **原因**：输入法非美式键盘
- **解决**：业务基类有输入法切换功能，确保调用
- **检查**：确认游戏窗口已绑定

### 坐标偏移
- **原因**：ImageGrab 用屏幕坐标，大漠截图用客户区坐标，混用导致偏移
- **解决**：统一使用大漠截图（客户区坐标），或在 ImageGrab 场景手动转换
- 详见 [AGENTS.md](../../AGENTS.md) 的待办事项

### 找图失败
- **原因**：BMP 模板不存在或相似度阈值过高
- **解决**：确认模板文件在 `resources/images/`，调整相似度阈值
- **检查**：资源管理器日志会记录路径解析

## 配置相关

### 英雄配置不生效
- **原因**：英雄互斥，后加载的英雄覆盖了目标英雄
- **解决**：检查 `extends` 中英雄的加载顺序，最后加载的独占生效
- 详见 [配置系统](../modules/config.md)

### 配置字段丢失
- **原因**：`[hero]` 做浅合并，子键完全覆盖
- **解决**：任务配置只写需要覆盖的字段，英雄基础属性在英雄 TOML 中定义
- 详见 [配置系统](../modules/config.md)

### 循环依赖报错
- **原因**：TOML 的 `extends` 形成循环
- **解决**：检查继承链，消除循环

## 任务运行相关

### 任务无法停止
- **原因**：任务入口未用 `run_with_float_window` 包装
- **解决**：用 `run_with_float_window` 包装，支持浮窗停止键

### 原子任务不执行
- **原因**：原子任务未注册到 `ATOMIC_TASK_REGISTRY`
- **解决**：在 `atomic/__init__.py` 中注册

### 组队任务同步异常
- **原因**：文件 IPC 读取超时或文件损坏
- **解决**：检查 `logs/team_ipc/` 下的文件，确认原子写入正常
- 详见 [组队框架](../modules/team.md)
