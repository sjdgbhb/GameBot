## 二、测试分层策略

### 2.1 单元测试（`tests/unit`）

单元测试使用 `MagicMock` 替换 `DmClient._com`、OCR 客户端和 Windows COM 依赖。

### 2.2 集成测试（`tests/integration`）

集成测试在真实配置文件上运行，验证配置加载、配置继承和向后兼容。

### 2.3 手动/真实环境测试（`tests/manual`）

需在 `.venv-dm` 32 位 Python 3.8 + 真实大漠插件 + 真实 KK/War3 窗口环境下执行。
