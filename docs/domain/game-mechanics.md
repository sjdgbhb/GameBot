# 九种兵器2 游戏机制

> 本文档帮助 AI 理解游戏背景，减少对游戏机制的猜测。
> 配置参数详见 `src/GameBot/config/data/war3/jiubing2/jiubing2.toml`。

## 游戏概述

「九种兵器2诸神战场」是魔兽争霸3的一张 RPG 地图。玩家选择英雄，通过完成任务、
刷怪、升级装备来提升实力。本项目自动化的是日常/周常等重复性任务。

## 游戏环境

- **平台**：KK 平台（魔兽争霸3的对战平台客户端）
- **窗口**：War3 窗口模式，客户区尺寸 1902x1033（所有坐标基于此尺寸）
- **流程**：KK 启动游戏 → War3 窗口出现（先出现玩家名行列，然后出现游戏加载画面） → 进入游戏（难度选择、地图初始化） → 游戏内操作 → 退出后自动回 KK房间

## 英雄系统

- 共 22 个英雄，每局只能选一个（英雄互斥）
- 每个英雄有：技能（Q/W/E/R/T等）、连招序列、物品栏配置、圣痕/卡牌/神碎配置
- 英雄配置位于 `config/data/war3/jiubing2/heroes/`，通过 `name = "war3.jiubing2.heroes.{hero_name}"` 和 `extends = ["war3.jiubing2"]` 继承游戏机制
- 英雄在选择界面有固定坐标，通过点击小地图切换视角位置，双击目标英雄即可选择

## 物品系统

物品栏共 6 格，每格有物品 ID 和快捷键。全局物品定义：

| ID | 名称 | 说明 |
|----|------|------|
| 0 | 拾取 | 拾取地面物品，通常在最后一格 |
| 1 | 血瓶 | 恢复生命 |
| 2 | 蓝瓶 | 恢复魔法 |
| 3 | 无敌 | 短暂无敌 |
| 4 | 米奈希尔传送卷轴 | 传送到米奈希尔 |
| 5 | 远古森林外围入口传送卷轴 | 传送到远古森林 |
| 6 | 跳刀 | 闪烁 |
| 7 | 鱼竿 | 钓鱼用 |
| 8 | 水晶 | 魔法水晶 |
| 9 | 宠物食物 | 喂宠物 |

物品快捷键从英雄配置的 `inventory` 列表获取，不硬编码。

## 场景系统

游戏有多个场景（地图区域），通过传送切换：

| 场景 | 配置文件 | 说明 |
|------|----------|------|
| 黑石城 | scenes/blackstone_city.toml | 城门骚扰任务地点 |
| 森之城 | scenes/forest_city.toml | 迅猛野兽任务地点 |
| 米奈希尔 | scenes/menethil.toml | 中转场景 |
| 皇宫 | scenes/palace.toml | 进入无尽的入口 |
| 卡米村 | scenes/kami_village.toml | 毒蛇/蛇蛋/小炎蛇任务地点 |

每个场景配置包含 NPC 位置、路线点等。

## 任务系统

### 原子任务（可重复完成的最小单元）
- **迅猛野兽**（森之城）：走到狄安娜 → 接任务 → 沿路线杀怪 → OCR检测完成 → 回NPC交任务
- **城门骚扰**（黑石城）：走到守卫队长 → 接任务 → 沿路线骚扰 → OCR检测完成 → 回NPC交任务
- **毒蛇**（卡米村）：类似流程
- **蛇蛋**（卡米村）：类似流程
- **小炎蛇**（卡米村）：要求本局已完成过一次毒蛇任务

### 声望任务
- **黑石城声望**：反复完成城门骚扰，按声望上限/每次收益反推次数（目标150点）
- **森之城声望**：反复完成迅猛野兽，按声望上限/每次收益反推次数（目标150点）
- **每日声望**：顺序编排黑石城声望 → 转场至森之城 → 森之城声望

### 成就任务
- **个人任务成就**：反复完成毒蛇/蛇蛋等任务直到达成指定次数

### 无尽任务
- **多局无尽**：完整流程 KK→War3→准备→进皇宫→进无尽→循环刷怪→退出，多局自动循环
- **单局无尽**：英雄已在无尽地图内，直接循环刷怪
- 按楼层循环清理怪物，有 BOSS 死亡检测和刷新计时

### 其他任务
- **钓鱼**：自动抛竿、找色检测中钩、OCR检测钓鱼成功次数
- **巡逻拾取**：路线循环杀怪，AI检测地面宝箱，OCR识别物品名称，自动拾取目标物品
- **升级圣痕**：交替执行城门骚扰（获取升级机会）与圣痕升级，直到所有词条达标

## 游戏内系统

### 圣痕系统
- 通过聊天指令读取圣痕（`-shload`）
- F2 打开圣痕界面
- 三套圣痕（通过商城购买最多可有三套圣痕，否则只有一套），各有开关坐标
- 各词条有数值上限（生命值350、暴击伤害50等）
- 升级圣痕需要先获得升级机会（通过完成任务）

### 卡牌系统
- F4 打开卡牌界面
- 5行7列卡牌网格，有固定间距
- 可装备/重置卡牌

### 神碎系统
- F3 打开神碎界面
- 每页4条神碎，可翻页（通过商城购买或达成成就，最多有3页）
- 可激活/共鸣/吸收神碎

### 宠物系统
- 宠物饱腹感每分钟衰减（约3%）
- 需要定期喂食（符文礼包加30%饱和度，腐肉35%）
- 喂食间隔约9.5分钟

### 属性面板
- 右上角属性面板（英雄属性/宠物属性）可折叠/展开
- 折叠后避免遮挡游戏画面

### 技能面板
- 3行4列技能格子，有固定间距
- 通过点击格子学习技能

## 游戏内指令

| 指令 | 语义 |
|------|------|
| `-delh` | 清理英雄附近地面物品 |
| `-del` | 清理无尽地图物品 |
| `-rw` | 查询任务进度弹窗 |
| `-load3` | 读取存档（示例，具体看英雄配置） |
| `-shload` | 读取圣痕 |

## 难度系统

难度选项：普通、困难、噩梦、地狱、诸神的黄昏、折磨一~折磨五。
通过 OCR 识别难度选项并点击选择，默认「普通」，任务配置中可覆盖。

## 任务进度弹窗

发送 `-rw` 后弹出任务进度弹窗，最多显示 3 个任务进度。
弹窗在屏幕中心偏上位置，右上角有 X 关闭按钮。
OCR 检测弹窗内容判断任务完成状态。
