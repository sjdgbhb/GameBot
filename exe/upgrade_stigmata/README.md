## 简介

魔兽争霸3"九种兵器2"升级圣痕脚本：交替执行城门骚扰（获取升级机会）→ 走到圣痕 NPC → 自动选择未满词条升级，直至全部达标。

**注意：本工具仅适用于 SSR 圣痕。**

## 环境要求

- Windows 10/11（64 位），KK 平台
- War3 窗口模式 1920×1080，视距 3000
- 首次运行需**右键 → 管理员身份运行**（注册大漠插件）
- 注意 dm/dm.dll 有时会被系统删除（白名单设置：Windows 安全中心 → 病毒和威胁防护 → 排除项 → 添加该文件）

## 快速开始

1. 进入游戏，英雄**无需额外装备**
2. 英雄站在**黑石城守卫队长**附近
3. 运行 `upgrade_stigmata.exe`，5 秒内切回 war3 窗口，自动开始
4. 按**小键盘减号（Num -）**停止

## 配置文件

| 文件 | 用途 |
|---|---|
| `config.toml` | 常用参数（战斗模式、循环间隔等），优先级最高 |

### 常用参数

```toml
[tasks.others.upgrade_stigmata]
combat_mode = "auto_attack"    # auto_attack（全程平A）/ cast_skills（自动施法）
loop_interval_time = 1.0       # 两次升级循环之间的间隔（秒）
clear_nearby_probability = 0.30 # 路线点清理附近物品概率（0~1），0 = 禁用
```

## 注意事项

- 任务不依赖特定英雄，任意英雄均可使用
- **仅限 SSR 圣痕**使用，其他品质圣痕的词条不同，配置不适用，也没升级的必要
- 英雄初始站位：黑石城守卫队长附近（城门骚扰任务的接取 NPC）
- 升级逻辑：每次升级前按 F2 打开圣痕面板，OCR 读取各词条当前数值，选择未达上限且差距最大的词条进行升级；全部达上限则自动停止
- 每完成一次城门骚扰获得一次升级机会，机会不可叠加，故采用"骚扰 → 升级"交替循环
