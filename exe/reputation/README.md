## 简介

魔兽争霸3"九种兵器2"每日声望脚本：黑石城声望（城门骚扰）+ 森之城声望（迅猛野兽），各 150 点。

## 环境要求

- Windows 10/11（64 位），KK 平台
- War3 窗口模式 1920×1080，视距 3000
- 首次运行需**右键 → 管理员身份运行**（注册大漠插件）
- 注意 dm/dm.dll 有时会被系统删除（白名单设置：Windows 安全中心 → 病毒和威胁防护 → 排除项 → 添加该文件）

## 快速开始

1. 进入游戏，英雄装备**远古森林外围入口传送卷轴**（默认放在物品栏第5格，快捷键5）— 只有做森之城声望才需要
2. 英雄站在**黑石城守卫队长**附近（只做森之城声望则无初始站位要求）
3. 根据需要配置好config.toml（全做还是单独做某个声望），运行 `reputation.exe`，5 秒内切回 war3 窗口，自动开始
4. 按**小键盘减号（Num -）**停止

## 配置文件

| 文件 | 用途 |
|---|---|
| `config.toml` | 常用参数（任务开关、声望目标等），优先级最高 |

### 任务开关

```toml
[tasks.reputation.daily_reputation]
enable_blackstone = true       # 是否执行黑石城声望，true = 做黑石城声望，false = 不做黑石城声望
enable_forest = true           # 是否执行森之城声望，true = 做森之城声望，false = 不做森之城声望
```

### 声望参数

```toml
[tasks.reputation.daily_reputation.blackstone]
target_reputation = 150       # 每日声望上限
reputation_per_run = 5         # 每次城门骚扰任务获得的声望

[tasks.reputation.daily_reputation.forest]
target_reputation = 150        # 每日声望上限
reputation_per_run = 10        # 每次迅猛野兽任务获得的声望
```

## 注意事项

- 任务不依赖特定英雄，任意英雄均可使用
- 森之城声望需装备远古森林外围入口传送卷轴（默认放在物品栏第5格，快捷键5），黑石城声望无需额外装备
- 英雄初始站位：黑石城守卫队长附近（城门骚扰任务的接取 NPC），只做森之城声望则无初始站位要求
- 执行顺序：先黑石城声望（若启用）→ 再森之城声望（若启用，会自动传送转场）
