# 刷装备自动化工具

## 简介

魔兽争霸3"九种兵器2"刷装备脚本：巡逻杀怪 → AI 检测宝箱 → OCR 识别物品 → 自动拾取。

## 环境要求

- Windows 10/11（64 位），KK 平台
- War3 窗口模式 1920×1080，视距 3000
- 首次运行需**右键 → 管理员身份运行**（注册大漠插件）
- 注意dm/dm.dll有时候会被系统删除（白名单设置：windows安全中心-病毒和威胁防护-“病毒和威胁防护”设置-管理设置-排除项-将该文件添加进排除项）

## 快速开始

1. 进入游戏，英雄装备宠物食物（默认快捷键5，根据食物配置喂食间隔），荒漠废墟需额外装备跳刀（默认快捷键4）
2. 设置好目标装备数量（desired_items配置）
3. 英雄站在路线起点（奇异之地：裂隙旁石笋右侧；荒漠废墟：裂隙左侧未拉怪处）
4. 运行 `patrol_loot.exe`，5 秒内切回war3窗口，自动开始
5. 按**小键盘减号（Num -）**停止

## 配置文件

| 文件 | 用途 |
|---|---|
| `config.toml` | 常用参数（路线方案、拾取目标、喂食间隔等），优先级最高 |
| `patrol_loot.toml` | 完整任务配置（含路线点坐标、等待时间），需改路线点时编辑此文件 |

### 常用参数（config.toml）

- `route_scheme`：路线方案，`"奇异之地"` 或 `"荒漠废墟"`
- `desired_items`：拾取目标及数量，`count = 0` 表示只识别不拾取
- `patrol.rounds`：循环轮数，`0` = 无限
- `pet.feeding_interval`：喂食间隔（分钟）
- `chest.ai_conf`：宝箱检测置信度，漏检降低、误检提高

### 路线点参数（patrol_loot.toml）

```toml
[[tasks.others.patrol_loot.route_presets.points]]
desc = "路线点描述"
mini_coords = [121, 928]   # 小地图坐标
coords = [1459, 396]       # 屏幕坐标
time = 5                   # 等待时间（秒）
walk_mode = 1              # 0=右键移动, 1=A键攻击移动, 2=M键移动
```

## 注意事项

- 宠物食物（id=9）必须装备，否则任务拒绝启动
- 拾取（id=0）固定第6格，勿修改
- 储物箱满或目标物品拾取完毕后，自动停止巡逻转为仅喂宠物模式
