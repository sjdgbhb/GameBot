# 钓鱼自动化工具 — 使用说明

## 简介

本工具是魔兽争霸3 RPG地图"九种兵器2"的钓鱼自动化脚本，采用大漠插件实现屏幕识别和自动操作。

**功能特点：**
- 快速模式钓鱼（找色/找图 + 预判收竿）
- 自动抛竿、检测中钩、收竿
- 定时清理英雄附近地面物品
- 浮窗显示运行进度，小键盘减号一键停止

## 环境要求

- **操作系统**：Windows 10/11（64 位）
- **游戏平台**：KK 平台
- **游戏设置**：
  - War3（非重置版），窗口模式，窗口大小 1920×1080
  - 分辨率：1920×1080
  - 启用视距调整，视距高度 3000
- **大漠插件**：已包含在 `dm/` 目录中，首次运行需管理员权限注册

## 快速开始

1. 打开 KK 平台，启动九种兵器2，进入游戏
2. 确保英雄已装备鱼竿，且鱼竿快捷键与 `config.toml` 中一致（默认为4）
3. 英雄站在**下方有水**的位置（推荐卡米村复活石水域、米奈希尔瞭望塔水域），附近不要有与中钩红色很接近的颜色，以免影响检测
4. 双击 `fishing.exe`（首次运行需**右键 → 管理员身份运行**注册大漠插件）
5. 弹出倒计时浮窗（5 秒），请在倒计时结束前切换到游戏窗口
6. 自动开始钓鱼，按**小键盘减号（Num -）**停止

> 首次使用建议先将 `config.toml` 中 `is_test_check` 改为 `true`，运行一次测试中钩检测区域是否正确，确认后再改回 `false` 正式钓鱼。

## 配置说明

`config.toml` 中可修改的参数如下：

### 窗口尺寸

```toml
[war3]
client_size = [1902, 1033]   # 游戏窗口客户区大小 [宽, 高]
```

必须与游戏实际窗口客户区一致，所有坐标均以此尺寸标定。

### 鱼竿快捷键

```toml
[[hero.inventory]]
slot = 3       # 物品栏格子（0~5 对应第1~6格）
id = 7         # 鱼竿（请勿修改）
hotkey = "4"   # 钓鱼快捷键，此处配置的是物品栏第4格快捷键
```

如果鱼竿放在第4格，快捷键是"4"，则保持 `slot = 3, hotkey = "4"` 不变。
如果鱼竿放在第1格，快捷键是"1"，则改为 `slot = 0, hotkey = "1"`。

### 钓鱼参数

```toml
[tasks.others.fishing]
max_times = 10000            # 抛竿次数（达到后自动停止）
fishing_interval_time = 0.5  # 每次钓鱼间隔（秒）
hook_coords = [943, 554]     # 鱼钩抛出位置（屏幕坐标）
clear_nearby_interval = 120  # 定时清理地面物品间隔（秒），0=禁用
is_test_check = false        # 测试中钩检测区域（true=先抛一竿测试区域再正式钓鱼）
mode = 0                     # 中钩检测模式：0=找色（红色三角形填充），1=找图
```

### 中钩检测参数

```toml
[tasks.others.fishing.check]
retract_lead_time = 0.1                    # 预判收竿提前量（秒）
hook_sim = 1                               # 相似度（找色/找图通用，1=完全匹配）
status_area_coords = [850, 350, 1200, 450] # 检测区域 [左,上,右,下]
hook_delta_color = '202020'                # 颜色色差容差
hook_color = 'ff0000'                      # 找色模式：中钩三角形填充颜色（红色）
hook_status_image = "hook_status.bmp"      # 找图模式：检测图片文件名
hook_timeout = 15                          # 等待中钩超时（秒）
```

**检测模式说明：**
- `mode = 0`（默认）：找色模式，扫描检测区域内的红色三角形填充，无需图片文件
- `mode = 1`：找图模式，匹配 `hook_status.bmp` 图片，需确保图片文件存在

**调参建议：**
- **收竿偏晚**（总是晚1-2格）：增大 `retract_lead_time`（如 0.15、0.2）
- **收竿过早**（红色未出现就收）：减小 `retract_lead_time`（如 0.05）
- **检测不到中钩**：检查 `status_area_coords` 是否覆盖了三角形填充区域，或降低 `hook_sim`
- **误触发收竿**：提高 `hook_sim`，或缩小 `status_area_coords` 检测区域
- **找图模式不生效**：确认 `mode = 1` 且 `resources/images/hook_status.bmp` 文件存在
