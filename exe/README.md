# 九种兵器2 自动化工具

## 免责声明

本工具为魔兽争霸3"九种兵器2"地图的自动化辅助脚本，仅供学习和个人娱乐使用。

- 本工具不修改游戏客户端、服务器数据或任何游戏文件，仅通过模拟鼠标键盘操作和屏幕图像识别实现自动化
- 使用本工具可能违反游戏的使用条款，由此产生的一切后果（包括但不限于账号封禁）由使用者自行承担
- 本工具开发者不对因使用本工具而导致的任何直接或间接损失负责
- 下载或使用本工具即表示您已阅读并同意上述声明

## 简介

本工具包含四个独立的前台自动化任务，做什么任务就运行对应的 EXE：

| EXE | 功能 |
|---|---|
| `钓鱼.exe` | 快速模式钓鱼（找色 + 预判收竿） |
| `刷装备.exe` | 巡逻杀怪 → AI 宝箱检测 → OCR 物品识别 → 自动拾取 |
| `每日声望.exe` | 黑石城声望（城门骚扰）+ 森之城声望（迅猛野兽），各 150 点 |
| `升级圣痕.exe` | 城门骚扰获取升级机会 → 走到圣痕 NPC → 自动选择未满词条升级 |

四个 EXE 共享 `dm/`（大漠插件）、`dm_bridge/`（32 位大漠 COM 桥接子进程）和 `resources/`（模型/图片）。推理在主 EXE 进程内直接进行，无需独立推理子进程。

## 环境要求

- Windows 10/11（64 位），KK 平台
- kk平台设置：War3（非重置版） 窗口模式，窗口大小 1920×1080，游戏分辨率 1920×1080，视距 3000，系统分辨率最好也改成 1920×1080，改好之后再次打开设置确认一下
- 首次运行需**右键 → 管理员身份运行**（注册大漠插件）
- 注意 dm/dm.dll 有时会被系统删除（白名单设置：Windows 安全中心 → 病毒和威胁防护 → 排除项 → 添加该文件）

## 快速开始

1. 打开 KK 平台，启动九种兵器2，进入游戏
2. 根据要做的任务，参考下方说明做好准备工作（装备、站位等）
3. 双击对应的 EXE（首次运行需右键管理员身份运行）
4. 弹出倒计时浮窗（5 秒），请在倒计时结束前切换到游戏窗口
5. 自动开始，按**小键盘减号（Num -）**停止

## 钓鱼

### 准备

- 英雄装备鱼竿（默认物品栏第4格，快捷键4）
- 英雄站在**下方有水**的位置（推荐卡米村复活石水域、米奈希尔瞭望塔水域）
- 附近不要有与中钩红色很接近的颜色（比如炎魔、凤凰这种有红色的需要换掉），如果有问题就换个位置试试

### 配置文件：`钓鱼_config.toml`

```toml
[tasks.others.fishing]
max_times = 10000            # 抛竿次数（达到后自动停止）
fishing_interval_time = 0.5  # 每次钓鱼间隔（秒）
mode = 0                     # 中钩检测模式：0=找色，1=找图

[tasks.others.fishing.check]
retract_lead_time = 0.1      # 预判收竿提前量（秒），收竿偏晚则调大
status_area_coords = [850, 350, 1200, 450]  # 检测区域
```

> 首次使用建议先将 `is_test_check` 改为 `true`，测试中钩检测区域是否正确。

## 刷装备

### 准备

- 英雄装备宠物食物（默认物品栏第5格，快捷键5）
- 荒漠废墟路线需额外装备跳刀（默认物品栏第4格，快捷键4）
- 英雄站在路线起点（奇异之地：裂隙旁石笋右侧；荒漠废墟：裂隙左侧未拉怪处）
- 一般来说，脚本运行后，游戏窗口左上角刚好位于屏幕的左上角，如果不是，则需要手动将窗口移至左上角（不能被遮挡、不能移出屏幕外），然后再运行脚本，否则可能出现意外

### 配置文件

| 文件 | 用途 |
|---|---|
| `刷装备_config.toml` | 常用参数（路线方案、拾取目标、喂食间隔、路线点等） |

```toml
[tasks.others.patrol_loot]
route_scheme = "奇异之地"     # 路线方案：奇异之地 或 荒漠废墟
```

- 宠物食物（id=9）放在第5格
- 拾取（id=0）固定第6格，勿修改

## 每日声望

### 准备

- 只有做森之城声望才需要装备**远古森林外围入口传送卷轴**（默认物品栏第5格，快捷键5）
- 做黑石城声望需英雄站在**黑石城守卫队长**附近；只做森之城声望则无初始站位要求

### 配置文件：`每日声望_config.toml`

```toml
[tasks.reputation.daily_reputation]
enable_blackstone = true    # true = 做黑石城声望，false = 不做
enable_forest = true        # true = 做森之城声望，false = 不做
```

- 执行顺序：先黑石城声望（若启用）→ 再森之城声望（若启用，会自动传送转场）
- 任务不依赖特定英雄，任意英雄均可使用

## 升级圣痕

### 准备

- 英雄**无需额外装备**
- 英雄站在**黑石城守卫队长**附近

### 配置文件：`升级圣痕_config.toml`

```toml
[tasks.others.upgrade_stigmata]
combat_mode = "auto_attack"       # auto_attack（平A）/ cast_skills（自动施法）
loop_interval_time = 1.0          # 两次升级循环间隔（秒）
clear_nearby_probability = 0.30   # 路线点清理附近物品概率，0 = 禁用
```

- **仅限 SSR 圣痕**使用，其他品质圣痕的词条不同，配置不适用，也没升级的必要
- 升级逻辑：每次升级前按 F2 打开圣痕面板，OCR 读取各词条当前数值，选择未达上限且差距最大的词条进行升级；全部达上限则自动停止
- 每完成一次城门骚扰获得一次升级机会，机会不可叠加，故采用"骚扰 → 升级"交替循环

## 构建说明（开发者）

打包脚本 `exe/build_all.py` 将四个任务打包到同一目录。各任务子目录（`exe/fishing/`、`exe/patrol_loot/` 等）下的 `data/` 是 PyInstaller 打包时用的**精简配置快照**，组装阶段会用主仓库完整配置 `src/GameBot/config/data/` 覆盖包内的 `_internal/config/data/`（见 `build_all.py` 步骤 3.1.1）。

因此修改 `src/GameBot/config/data/` 中的配置后无需同步 `exe/<task>/data/`——它们仅在单独打包单个任务（不经组装）时生效。正常 `uv run python exe/build_all.py` 全流程打包以主仓库配置为准。

构建命令：
```bash
uv run python exe/build_all.py            # 完整构建（打包 + 组装）
uv run python exe/build_all.py --assemble  # 仅组装（主 EXE 和 dm_bridge 已打包好）
uv run python exe/build_all.py --update <任务名>  # 仅更新单个任务到已有包
```
