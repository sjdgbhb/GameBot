# 九种兵器2 无尽脚本

## 免责声明

仅供学习和个人娱乐使用。不修改游戏客户端和服务器数据，仅模拟键鼠操作和屏幕识别。使用可能违反游戏条款，后果（含账号封禁）自行承担。使用即表示同意。

## 运行前准备

1. **KK 平台设置**：War3（非重置版）、窗口模式（后台模式建议鼠标不锁定在窗口内）、窗口 1920×1080、分辨率 1920×1080、物品栏快捷键设置为 1~6
2. **首次运行**：右键 exe → 以管理员身份运行（注册大漠插件）
3. 安全软件删了 `dm/dm.dll` 的话，把本目录加入 Windows 安全中心排除项

## 脚本功能

| EXE | 运行前的状态 | 功能 |
|---|---|---|
| `多局无尽.exe` | 账号在自己创建的 **KK 密码房**内 | 建房开始→选难度→进无尽→循环刷怪→退出，自动打多局 |
| `单局无尽.exe` | 已在无尽地图内，英雄站在 **3 点钟石笋**位置 | 直接开刷 |

## 配置文件

- `多局无尽.toml` / `单局无尽.toml` — 基础配置，单开用
- `多局无尽_<玩家名>.toml` / `单局无尽_<玩家名>.toml` — 变体配置，多开用

参数含义看文件内注释，改完保存重新启动即生效。

## 使用示例

### 单开

1. 账号进入自己的 KK 密码房（多局），或进无尽地图站好位（单局）
2. 双击 exe → 选择 `多局无尽.toml` → 启动
3. 5 秒倒计时后自动开始；**Num - 或浮窗 ✕ 停止**

### 多开（能避免本机两个同样的kk或war3相互影响），必须后台模式，以下是两个账号同时做多局无尽任务的例子，玩家名根据实际情况修改

1. 复制 `多局无尽_东东的西.toml`，改名 `多局无尽_玩家A.toml`，`target_player` 改成玩家A；
   玩家B同样再复制一份 `多局无尽_玩家B.toml`
2. 两个账号各自进自己的 KK 密码房
3. 双击 `多局无尽.exe` → 选 `多局无尽_玩家A.toml` → 启动
4. 再双击 `多局无尽.exe` → 选 `多局无尽_玩家B.toml` → 启动

- 同一配置不能重复启动
- 认领失败会自动停止，不会操作到对方窗口
- **Num - 是全局热键，两个脚本会一起停**；单独停用各自的浮窗 ✕

## 出问题看日志

`logs/` 目录下按日期分文件，`*_error.log` 只看错误。

## 注意
1. 不要轻易移动窗口，尤其是war3加载页面或者脚本刚启动不久时，浮窗可以任意移动
2. 前台模式，窗口不能被遮挡，不能动鼠标键盘；后台模式，窗口可以被遮挡，不要最小化、移出屏幕外，可以动鼠标键盘，关闭显示器、休眠、屏锁等可能导致异常
3. 多局无尽任务有圣痕、神碎（默认不覆盖神碎，在正确配置的情况下，如要覆盖，可以将is_absorb = false修改为is_absorb = true）、卡牌、物品栏装备要求，需要自己根据实际情况修改配置文件
